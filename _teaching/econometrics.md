This course covers fundamental and advanced econometric methods for analyzing economic data, focusing on practical applications and quantitative techniques.

### Key Topics Covered:
* Linear Regression Analysis and Ordinary Least Squares (OLS)
* Diagnostic Testing: Multicollinearity, Heteroskedasticity, and Autocorrelation
* Time Series Analysis and Panel Data Fundamentals
* Practical empirical estimation using statistical software (Stata)
