This course focuses on practical data analysis techniques applied to economic research and market insights, bridging theoretical concepts with empirical computational tools.

### Key Topics Covered:
* Exploratory Data Analysis (EDA) and data wrangling for economic datasets
* Descriptive and inferential quantitative analysis
* Data visualization and reporting techniques
* Practical implementation using Stata and statistical software
